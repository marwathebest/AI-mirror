# AI Mirror — بوابة عالم آخر

تجربة تفاعلية حيّة بالذكاء الاصطناعي: يقف الزائر أمام الشاشة، فتنفتح بوابة سحرية، ويظهر من خلالها وقد تحوّل بالكامل إلى شخصية من عالم آخر — الوجه والشعر والملابس والخلفية — وكل ذلك **لحظياً** ويتحرك معه حركة بحركة.

صُمّمت للمعارض والفعاليات وشاشات الكشك (Kiosk)، دون أي لمس من الزائر.

---

## الفكرة

- **يكتب الزائر من يريد أن يصبح** (أو يختار تحوّلاً جاهزاً): محارب جليد، أميرة سايبربانك، ملك النار…
- **يقف أمام الشاشة** فتنفتح البوابة تلقائياً بحلقة ضوء وشرر.
- **يظهر داخل البوابة متحوّلاً** إلى الشخصية التي وصفها، في عالمها، ويتحرك معه التحوّل مباشرة.
- **صورته الحقيقية لا تظهر أبداً**؛ الشاشة تعرض فقط الفيديو المتحوّل القادم من الذكاء الاصطناعي.
- **عندما يغادر** تُغلق البوابة ويتوقف الاتصال بالذكاء الاصطناعي، فلا تُحتسب تكلفة دون زائر.

## المزايا

| الميزة | التفاصيل |
|---|---|
| تحوّل لحظي | فيديو حي بدقة 720p وحتى 30 إطاراً في الثانية |
| وصف حر | الزائر يصف الشخصية والملابس والعالم بكلماته |
| تحوّلات جاهزة | ستة اقتراحات بضغطة واحدة |
| فتح تلقائي | البوابة تنفتح عند وجود شخص وتُغلق عند مغادرته |
| خصوصية | لا تُعرض صورة الكاميرا الأصلية ولا تُحفظ أي صورة |
| تحكم بالتكلفة | الاتصال يعمل فقط أثناء وجود زائر، وبحد أقصى 3 دقائق للزيارة |
| بدون لمس | مناسبة لشاشات العرض الكبيرة |

## كيف تعمل

```
الكاميرا ──► كشف وجود شخص (MediaPipe، داخل المتصفح)
   │
   └──► Decart Realtime (Lucy 2.6) ──► فيديو متحوّل ──► يُعرض داخل البوابة
                ▲
        مفتاح مؤقت من السيرفر (5 دقائق)
```

- **كشف الوجود:** نموذج MediaPipe لفصل الشخص يعمل محلياً في المتصفح، ويُستخدم فقط لمعرفة هل يوجد شخص أمام الشاشة؛ لا يُرسم ولا يُعرض.
- **التحوّل:** بث الكاميرا يُرسل عبر WebRTC إلى نموذج Decart اللحظي مع وصف التحوّل، ويعود فيديو متحوّل يُرسم داخل البوابة.
- **الأمان:** مفتاح Decart الدائم يبقى في السيرفر فقط، والمتصفح يحصل على مفتاح مؤقت لكل جلسة.
- **البوابة والعوالم:** الحلقة والجزيئات والعوالم الخلفية مرسومة بالكود (Canvas) دون أي صور.

## التقنيات

- **Node.js + Express** — سيرفر خفيف يقدّم الصفحة ويصدر المفاتيح المؤقتة
- **[Decart Realtime API](https://docs.platform.decart.ai)** (`@decartai/sdk`) — تحويل الفيديو لحظياً
- **[MediaPipe Tasks Vision](https://ai.google.dev/edge/mediapipe)** — كشف الوجود في المتصفح
- **HTML / CSS / JavaScript** بدون أي إطار عمل

## التشغيل

### المتطلبات
- Node.js 22.9 أو أحدث
- كاميرا ويب
- اتصال إنترنت جيد
- حساب ومفتاح API من [Decart](https://platform.decart.ai)

### الخطوات

1. ثبّت الحزم:
   ```bash
   npm install
   ```
2. انسخ `.env.example` إلى ملف باسم `.env` وضع فيه مفتاحك:
   ```
   DECART_API_KEY=your-key-here
   ```
3. شغّل السيرفر:
   ```bash
   npm start
   ```
4. افتح **http://localhost:3000** في Chrome أو Edge واسمح باستخدام الكاميرا.

> لا تفتح `index.html` مباشرة من المجلد؛ الكاميرا والذكاء الاصطناعي يحتاجان أن تُفتح الصفحة من السيرفر.

### أثناء العرض
- زر **⛶** لملء الشاشة.
- زر **غيّر التحوّل** للعودة إلى شاشة الوصف.
- أبقِ نافذة الترمنال مفتوحة طوال العرض.

## التكلفة

يُحتسب استخدام Decart بالثانية أثناء وجود زائر فقط (حوالي 0.02 دولار للثانية حسب [صفحة الأسعار](https://docs.platform.decart.ai/getting-started/pricing)). يمكن تعديل الحد الأقصى للزيارة من `MAX_VISIT_MS` في `public/app.js`.

## هيكل المشروع

```
AI-mirror/

│   ├── styles.css     # التصميم

└── package.json
```

## التخصيص

- **التحوّلات الجاهزة:** في `public/index.html` داخل عناصر `.suggestion` (النص في `data-prompt`).
- **العوالم وألوان البوابة:** في مصفوفة `worlds` داخل `public/app.js`.
- **حساسية فتح البوابة:** `PRESENT_COVERAGE` و`CLOSE_AFTER_MS` في `public/app.js`.
